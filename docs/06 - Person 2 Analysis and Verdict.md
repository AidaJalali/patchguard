# Person 2: diff analysis, correlation, oracle, and verdicts

## Implemented modules

- `diff_parser.diff_analyzer`: committed Git snapshots, unified hunks, Clang C/C++ function spans and direct-call graph; configurable one/two-hop neighborhood.
- `correlator.correlator`: direct frames, caller frames, allocation/free frames supplied by diagnostics, static caller-to-callee links, and differential coverage.
- `oracle.functional_oracle`: explicit independent JSON reference expectations; exact/regex/JSON stdout, stderr regex, exit codes, and valid-input labels.
- `classifier.verdict`: five-state findings from matching test/build pairs, replay evidence, oracle results, and patch correlation.

All modules import with `PYTHONPATH=src`. Install Clang alongside GCC/binutils; no new Python dependencies were introduced. The CI workflow now installs Clang.

## Source analysis

```python
from diff_parser.diff_analyzer import analyze_git
patch = analyze_git("/path/to/target", "BASE_REF", "PATCHED_REF",
                    compile_args=("-Iinclude", "-DENABLED=1"))
print(patch.modified_functions("patched"))
print(patch.diagnostics)
```

Both refs are resolved to commits before commands use them. The worktree is never checked out or changed. Regular source/header files are copied from each tree to separate temporary directories. Relative `-I` flags refer to those snapshots. Unchanged translation units provide cross-file graph context. Git renames appear as deletion/addition; old/new hunk coordinates stay separate. Zero-length hunk sides do not pretend to contain changed lines.

Clang supplies syntax ASTs, never target executions. Functions generated by macros without usable source offsets are omitted. Unsupported generated headers, missing system dependencies, or syntax errors produce diagnostics and conservative Inconclusive correlation. This does not run target build commands or discover compilation databases; callers must provide the necessary attached include/define/language flags. The same compile flags currently apply to both versions.

Direct function/member calls retain Clang symbol identity and internal/external linkage. Taking a function's address is not a direct call. Static functions and anonymous-namespace functions cannot satisfy references from another translation unit. C++ overloads/namespaces are resolved by exact mangled symbols when available; unresolved/ambiguous targets and indirect calls are not guessed. Manually supplied name-only call targets are restricted to their own file. Stack-frame matching still uses the supplied function names, so ambiguous/demangled frame names may require normalization. Source mapping assumes UTF-8. A source-location normalization adapter is needed if sanitizer paths refer to unrelated container roots.

## Correlation

```python
from correlator.correlator import correlate
link = correlate("finding-1", execution, patch, depth=2)
```

Direct crash/allocation/free frames inside a modified function near changed lines yield HIGH. Observed changed caller frames and unambiguous static caller-to-callee paths yield MEDIUM. Coverage can yield MEDIUM when the supplied base/patched covered-line sets differ and a patched changed line is executed. Coverage sets alone do not establish temporal ordering or causality; the evidence description does not claim those.

No link, incomplete AST analysis, or ambiguous frame identity yields INCONCLUSIVE. Line proximity without function identity is insufficient. Base frames are compared with base spans, patched frames with patched spans. `extra_frames` accepts allocation/free sites from Person 1; those fields are not fabricated by this module.

## Oracle contract

```json
{
  "reference_source": "Independent specification or reference-suite identifier",
  "tests": [
    {
      "test_id": "invalid_length",
      "expected_exit_code": 2,
      "is_valid_input": false,
      "expected_stdout_exact": "",
      "expected_stderr_pattern": "invalid"
    }
  ]
}
```

Exactly one stdout matcher is required: `expected_stdout_exact`, `expected_stdout_regex` (full-string match), or `expected_stdout_json` (structural comparison; object key order ignored, booleans distinct from numbers). Stderr regex is optional and searches stderr. Whitespace is not silently trimmed. Crash/signal/timeout/OOM results never pass an oracle. Nonzero exit codes may be correct for rejected input.

`load_oracle(path)` records provenance; it does not certify TA approval. `evaluate(result, expectation)` evaluates one run. `evaluate_suite(results, suite)` requires every listed test on base/patched and release/sanitized, rejecting duplicates/missing cases.

## Classification and reporting

`classify_pair(finding_id, base, patched, correlation=..., base_oracle=..., patched_oracle=..., base_replay=..., patched_replay=..., base_artifact=..., patched_artifact=...)` returns a `Finding`; `Finding.to_dict()` is directly compatible with Person 4's `findings` list. Execution traces and oracle reasons are preserved in each finding. The global report completion flags remain the real pipeline coordinator's responsibility.

| Status | Required evidence |
| --- | --- |
| Fixed | Confirmed base crash, established patch correlation, patched does not crash and satisfies independent oracle |
| Incomplete Fix | Same confirmed crash on both versions, correlated to the patch; bypass inputs are separate test pairs |
| New Issue | Base did not crash or terminate by signal/limits, patched has a confirmed correlated crash |
| Functional Regression | Valid input passes base oracle and fails patched oracle, with neither run crashing or hitting limits; crash cases are considered security evidence first |
| Inconclusive | Missing reproduction/oracle/correlation, resource termination, flaky artifacts, unresolved crash identity, or a pair that establishes no finding |

Crash confirmation requires runtime mechanism/signal evidence and deterministic replay records. A reproducer with `is_flaky=True` remains inconclusive even with `3/3` successful initial replays. Release and sanitized builds must never be paired. Both-crashing cases with different signatures are not automatically called New Issue. Cross-version line shifts currently remain inconclusive until an upstream identity mapper establishes equivalence; the classifier does not loosen the shared crash-matching rule.

Ordinary passing functional tests should be recorded in execution/oracle results rather than manufactured as Fixed findings. Multiple findings are retained independently; Person 4 resolves the aggregate exit code.
